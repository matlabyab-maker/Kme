# Kme — Android Keyboard starter

A GitHub/MGit-ready Android Input Method Editor (IME) starter based on the supplied keyboard image.

## Current scope
- Uses the supplied keyboard image as a compact visual reference, optimized to **63.6 KB**.
- Implements an Android keyboard service and a working **Send** key action: it asks the focused site/app's editor to perform its configured editor action (for example, Send/Done/Go) and falls back to Enter when no action is available.
- This is the standard Android IME integration point; it cannot force a site's private blue send button to run. A website must expose a compatible editor action or handle Enter, and browser/site behavior varies.
- Image is shown as the keyboard's background/reference; individual keys are not yet mapped to touch zones. The next stage is mapping the Send region and then the remaining key regions.

## Build
Open this repository in Android Studio and build `:app:assembleDebug`, or push to GitHub and let the included Actions workflow build it. The workflow uses the standard Android setup action and Gradle wrapper validation.

## MGit
1. Extract this ZIP.
2. Create a GitHub repository named `Kme`.
3. In MGit, open the extracted local repository folder, initialize/add the GitHub remote, then commit and push.
4. The first commit should include the Gradle wrapper files if generated by Android Studio. This starter intentionally does not ship a fabricated wrapper JAR; the workflow installs Gradle and builds without relying on a missing `gradlew`.

## Enable keyboard
After installing the APK, go to Android Settings → System/Language & input → On-screen keyboard/Manage keyboards, enable **Kme**, then select it as the active keyboard.
